### 2.1 ブランドデータの利用ルール

- 保存するのは、商品名、カテゴリ、色、素材、価格、公式リンク、取得日時、販売状況、タグ付け用のサムネイル参照に限ります。
- ブランドの商品画像を自社サーバーに長期保存したり公開表示したりしません。表示するときは公式サイトへリンクします。
- 着用イメージにブランド商品が含まれる場合は「イメージ」と明記し、公式リンクを添えます。
- robots.txt と利用規約を守り、アクセス頻度を抑えます。CAPTCHA やボット対策は回避しません。
- 商用リリース前に、ブランドまたはアフィリエイト経路で利用許諾を確認します。

## 3. 雑誌とファッションメディア（第一弾の案）

### 3.1 選定基準

1. 読者の中心が若者で、日本市場に関係があること（海外メディアはトレンドとストリートカルチャーを重視）。
2. ニュースやゴシップではなく、**着こなしのテクニック、アイテムの組み合わせ、スナップ**が中心であること。
3. Web 版の記事が読めること。紙の誌面はネットで全文公開されないことが多いため、学習パイプラインは Web 記事を優先します。
4. メンズとレディース、ベーシック・トレンド・スポーツの各スタイルをカバーし、第一弾ブランドと合っていること。

## 4. 雑誌コンテンツの利用ルール

著作権リスクが最も高い部分です。すべての開発者が守ってください。

1. **抽象的なテクニックだけを抽出する**：例「同じ色相の 3 段階の明度で、内側から外側へ濃くする」。テクニックそのものはアイデアであり、表現をコピーするものではありません。
2. **自分の言葉で書き直す**：テクニックカードに原文をそのまま写した文章を入れてはいけません。引用は最大 1 文までとし、引用符と出典を付けます。
3. **本文と画像は保存しない**：学習パイプラインは読み終えたら、テクニックカードと出典（メディア名、記事タイトル、リンク、日付）だけを残します。
4. **アクセス方法を守る**：公開されている Web 記事、または許諾を得たコンテンツだけを読みます。電子雑誌の読み放題サービスは規約で AI による抽出を認めていないことが多いため、使う前に規約を確認するか許諾を得ます。
5. **人による審査**：候補カードは評価と人の審査を通過してから、正式なナレッジベースに追加します。

## 5. ソース品質の評価

四半期ごとにソース単位で次の指標を集計し、継続、優先度の引き下げ、入れ替えを判断します。

- 候補カードの審査通過率
- 正式な提案で引用された回数
- そのカードを引用した提案の保存率
- 既存カードとの重複率
