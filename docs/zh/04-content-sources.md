## 2. 品牌目录

| H&M | https://www2.hm.com/ja_jp/ | 快时尚 · 平价 | 平价趋势单品、配饰 |
| NIKE | https://www.nike.com/jp/ | 运动 | 球鞋、运动外套、运动风造型 |

### 2.2 M0 调研清单

每个品牌在 M0 完成以下调研，结果记录在内部表格中，并据此决定该品牌的数据获取方式：

| 调研项 | 需要确认的内容 |
| --- | --- |
| 联盟营销渠道 | 是否有面向日本市场的联盟计划；通过哪个联盟平台；是否提供商品数据 feed 或 API |
| 商品数据格式 | feed 包含哪些字段（商品编号、颜色、尺码、价格、库存、图片、类目） |
| 使用条款 | 官网条款中关于自动访问、数据使用、图片使用的规定 |
| robots.txt | 商品页、类目页、检索页是否允许访问 |
| 页面结构 | 商品页是否包含结构化数据（如 schema.org Product）；是否依赖客户端渲染 |
| 反爬措施 | 正常频率访问时是否被拦截 |
| 图片使用 | 是否允许在效果图中作为服装参考；是否允许在界面上展示 |

**判定规则**：有联盟商品数据的，使用联盟数据；没有联盟数据但条款与 robots 允许、页面可稳定读取的，使用公开页面；两者都不满足的，从首批品牌中替换。

### 2.3 字段映射

不论数据来自联盟 feed 还是公开页面，都映射到 `brand_items` 的统一字段：

| `brand_items` 字段 | 含义 | 来源说明 |
| --- | --- | --- |
| `brand` | 品牌代码 | 固定值，如 `uniqlo` |
| `external_id` | 品牌侧商品编号 | 同一商品不同颜色视为不同条目时，编号包含颜色代码 |
| `url` | 日本官网商品页链接 | 去除跟踪参数；联盟链接另存 |
| `title` | 商品名 | 保留日文原名 |
| `category` | StyleAI 统一类目 | 按第 2.4 节映射 |
| `colors` | 颜色 | 品牌颜色名保留在 `attributes`；hex 与占比由颜色提取算法计算 |
| `attributes` | 材质、廓形、衣长、品牌颜色名等 | 结构化字段优先，其余由视觉模型打标 |
| `price_jpy` | 含税价 | 促销价与原价同时记录 |
| `availability` | `in_stock` / `limited` / `sold_out` / `removed` | 任一尺码有货即为 `in_stock` |
| `line` | `staple` / `new` | 常年在售的基础款为 `staple`；当季上新为 `new` |
| `source` | `affiliate_feed` / `public_page` | |
| `fetched_at`、`last_checked_at` | 首次获取、最近检查时间 | |

各品牌的类目体系不同，统一映射到 StyleAI 的类目：

| StyleAI 类目 | 子类目示例 | 品牌侧常见名称 |

| `outerwear` | 夹克、大衣、开衫、马甲 | アウター、ジャケット、コート、カーディガン |

| `dresses` | 连衣裙、连体裤 | ワンピース、オールインワン |

### 2.5 更新频率

| 任务 | 频率 | 范围 |
| --- | --- | --- |
| 新品巡检 | 每天 | 各品牌“新品”类目 |
| 全量刷新 | 每周 | 所有已入库商品的价格、库存、下架状态 |
| 引用商品检查 | 每天 | 被用户保存的方案引用的商品 |
| 推荐前检查 | 实时 | 本轮推荐的商品，最近检查超过 24 小时的重新检查 |

访问频率上限：每个品牌站点平均每 2 秒不超过 1 个请求，并遵守 robots.txt 中的 `Crawl-delay`（如有）。

### 2.6 品牌数据使用规则

- 保存内容限于：第 2.3 节的字段，以及用于打标的临时图片引用。
- 不在对象存储中长期保存或公开展示品牌商品原图；界面展示时使用官网图片链接或联盟渠道允许的方式，并链接回官网。
- 效果图中出现品牌商品时，标注「效果示意」，并附官网链接。
- 遵守 robots.txt 与网站使用条款；不绕过验证码与反爬机制。
- 商业化上线前，与品牌或联盟营销渠道确认授权。

## 3. 杂志与时尚媒体

### 3.1 选择标准

1. 读者以年轻人为主，与日本市场相关（国际媒体侧重潮流与街头文化）。
2. 内容以**穿搭技巧、单品搭配、街拍**为主，而不是纯新闻或名人八卦。
3. 有网页版文章可以阅读。纸刊内容通常不在网上完整公开，学习管线优先读取网页文章。
4. 覆盖男装与女装，覆盖基础款、潮流、运动几种风格，和首批品牌对得上。

### 3.6 读取计划

| 项目 | 规则 |
| --- | --- |
| 频率 | 每个来源每周一次，读取上次之后发布的文章 |
| 文章发现 | 优先使用来源公开的 RSS 或站点地图；不抓取需要登录或付费的页面 |
| 读取的文章类型 | 穿搭特辑、单品搭配企划、街拍、季节趋势总结 |
| 跳过的文章类型 | 纯新闻、名人与私人生活报道、访谈、抽奖活动 |
| 广告文章 | 带有「PR」「Sponsored」「タイアップ」等标记的品牌合作文章一律跳过，避免把广告内容当作穿搭知识 |
| 数量上限 | 每个来源每周最多 20 篇 |
| 访问频率 | 每个站点平均每 5 秒不超过 1 个请求 |

## 4. 杂志内容使用规则

这是版权风险最高的环节，所有开发者都必须遵守：

1. **只提炼抽象技巧**：例如“同色系三个明度层级由内向外加深”。技巧本身属于思路，不直接复制表达。
2. **用自己的话重写**：技巧卡里不允许出现连续照抄的原文；引用原文最多一句，并加引号标注出处。
3. **不保存原文和图片**：学习管线读取后只保留技巧卡与出处（媒体名、文章标题、链接、日期）。
4. **访问方式合规**：只读取公开网页文章或已获授权的内容。「読み放題」等电子杂志订阅服务的条款通常不允许 AI 提取，使用前必须确认条款或取得授权。
5. **人工审核**：候选技巧卡必须经过评测与人工审核后，才能并入正式知识库。

### 4.1 照抄检查

候选卡生成后、进入审核之前，自动执行以下检查，任一项不通过即丢弃：

| 检查 | 规则 |
| --- | --- |
| 公共子串 | 技巧卡任一字段与原文之间，不存在长度超过 30 个字符（日文、中文）或 12 个英文单词的公共片段 |
| 引用数量 | 带引号的原文引用最多一处，且不超过一句 |
| 商品指向 | 技巧内容不包含具体商品名、价格或购买引导 |

原文只在检查期间保存在内存中，任务结束后丢弃。

### 4.2 出处记录

每张技巧卡至少记录一条出处：

```yaml
sources:
  - outlet: "FASHIONSNAP"
    title: "（文章标题原文）"
    url: "https://..."
    published: 2026-09-10
    accessed: 2026-09-14
```

同一技巧从多个来源学到时，合并为一张卡，追加出处。出处多的技巧，置信度相应提高。

## 5. 什么算一张好的技巧卡

学习管线与人工整理遵循同一标准。

| 标准 | 说明 |
| --- | --- |
| 可推广 | 适用于一类单品或一类场景，而不是某件具体商品 |
| 可执行 | 读完知道具体怎么做 |
| 有条件 | 说明适用的场景，以及什么时候不适用 |
| 可检查 | 尽量能对应到颜色、类目、廓形等可计算的属性 |

对比几个例子：

| 候选内容 | 判断 | 原因 |
| --- | --- | --- |
| “宽松卫衣配直筒牛仔裤时，把裤脚卷一折露出脚踝，下半身会更利落。” | 通过 | 可推广、可执行，适用条件清楚 |
| “这季一定要入手某品牌的 ¥12,900 工装夹克。” | 驳回 | 指向具体商品与价格，是购物推荐而非技巧 |
| “秋冬就要穿得有温度感。” | 驳回 | 无法执行，没有可检查的内容 |
| 与原文一模一样的一段描述 | 驳回 | 照抄 |
| “深色外套里面穿浅色内搭，领口露出 2～3 厘米，脸周会显得明亮。” | 通过 | 可执行；“领口露出”可以在效果图检查中验证 |

## 6. 来源质量评估

每个季度按来源统计以下指标：

| 指标 | 说明 |
| --- | --- |
| 候选卡审核通过率 | 通过数 / 候选数 |
| 被方案引用的次数 | 该来源产生的技巧卡被正式方案引用的次数 |
| 引用方案的收藏率 | 引用了该来源技巧卡的方案被收藏的比例 |
| 重复率 | 候选卡与已有技巧卡重复的比例 |
| 广告与无效文章比例 | 读取后被判定为广告或无技巧内容的文章比例 |

处理规则：

- 连续两个季度审核通过率低于 20%，或无效文章比例高于 60%：降级为 P1 或暂停。
- P1 来源的审核通过率与引用次数连续两个季度高于 P0 平均值：升级为 P0。

## 7. 来源的新增与移除

1. 提交 PR，修改本文的来源表格，说明理由与 robots、使用条款的确认结果。
2. PR 合入后，同步更新数据库中的 `content_sources` 表。
3. 移除来源时，已有技巧卡保留，出处中标记该来源已停用。
