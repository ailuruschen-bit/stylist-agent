# 立项文档

> 语言：**中文** · [日本語](../ja/01-project-charter.md) · [English](../en/01-project-charter.md)
> 状态：草案 v0.2 · 更新：2026-09-15 · 可视化版本：[charter.html](../charter.html)（本地用浏览器打开）

## 1. 一句话

**StyleAI v2 是一位和你共用衣橱的穿搭博主。** 它懂色彩与层次，读得懂你上传的每件衣服，会去品牌官网找单品，自己写提示词、自己决定怎么分阶段出图，并通过阅读时尚杂志不断学到新技巧。

## 2. 愿景与定位

Hackathon demo（[HackathonPJT · deploy/lite-budget](https://github.com/ailuruschen-bit/HackathonPJT/tree/deploy/lite-budget)）验证了“上传衣服 → 虚拟试穿出图”的链路。v2 的重心从**试穿**转向**造型**：告诉用户怎么穿、为什么这样穿好看，再用专业模特效果图证明这件事。

- **专业**：内置色彩、层次、廓形比例、材质对比等系统化知识，每个方案都讲得出理由。
- **会玩**：除了稳妥方案，也会提出绑腰、单袖穿、外套披肩等潮流穿法。
- **自主**：提示词、生图步骤、品牌检索都由 Agent 决定，不预写模板。
- **会成长**：持续阅读时尚内容，把新技巧沉淀进知识库。

## 4. 范围

**做**

- 与用户多轮深入对话，理解场合、心情和想尝试的风格
- 用户上传服装 → 分析、打标、入库，形成共享衣橱
- 检索品牌日本官网的经典款与新品，和用户衣橱混搭
- 给出完整方案：单品、层次、配色逻辑、穿法与理由
- 用内置模特生成专业效果图，复杂方案多阶段生成
- 从时尚杂志中提炼技巧，经评审后并入知识库

**不做**

- 收集或使用用户身材数据
- 生成用户本人形象，或基于用户照片的数字人
- 站内下单与支付（只跳转品牌官网）
- 订单导入与电商账号授权
- 原生移动 App
- 预先写死的提示词模板

## 6. 核心能力

| 代号 | 能力 | 要点 |
|---|---|---|
| KNOW | 穿搭知识内核 | 色彩、层次、廓形比例、材质图案；以“技巧卡”形式可检索、可引用 |
| CLOSET | 衣橱理解 | 抠图、打标（颜色 hex + 占比、材质、廓形、正式度等），识别“玩法潜力”（绑腰、单袖穿等） |
| SCOUT | 品牌单品探索 | 检索品牌日本官网的经典款与新品，缓存为目录；推荐只能引用目录中的真实条目 |
| COMPOSE | 搭配方案生成 | 结合对话、衣橱、品牌目录与技巧卡；先做规则校验再生图；稳妥方案 + 意外但成立的方案 |
| RENDER | 自主生图编排 | Agent 现写提示词；复杂方案规划为多阶段，逐步编辑并自检 |
| LEARN | 自我迭代学习 | 后台 Agent 阅读杂志，产出候选技巧卡；评测 + 人工审核后合入 |

## 7. 多阶段生图

1. **规划**：判断复杂度，输出结构化生图计划（阶段、参考图、必须保真的细节、验收要点）。
2. **基础造型**：模特参考图 + 内层与下装，优先保证颜色、印花、版型还原。
3. **叠穿**：在上一阶段结果上编辑加入外层。
4. **非常规穿法与细节**：绑腰、单袖、塞衣角、卷袖、配饰，逐项局部编辑。
5. **自检与修复**（循环）：对照计划逐项核对，不通过就回到对应阶段重做或局部修复，设重试上限。

简单方案一次成图再自检。

## 8. 内置模特库

- 用允许商用的生图模型生成“不存在的人”，每位模特有一组参考图，保证每次出图身份一致。
- 上线前做真人与名人相似度筛查，记录生成模型、日期与许可条款。
- 男女皆有，覆盖多种风格原型与族裔；Agent 按方案挑选，用户也可指定。
- 统一规格：棚拍柔光、无缝背景、全身入画、3:4 画幅。

## 10. 风险与合规

| 风险 | 等级 | 对策 |
|---|---|---|
| 杂志内容版权 | 高 | 只提炼抽象技巧并重写，保存出处，不存原文与图片；确认订阅服务条款 |
| 品牌官网抓取与商品图使用 | 高 | 优先联盟渠道；遵守 robots 与条款；只存元数据与链接；效果图标注示意 |
| 大型品牌官网反爬导致数据不稳定 | 高 | M0 起调研联盟营销渠道；不做任何反爬对抗 |
| 模特肖像与生成图版权 | 高 | 商用许可的生图模型；相似度筛查；记录来源与许可 |
| 服装还原失真 | 中 | 分割抠图保留原像素；多阶段编辑 + 视觉自检 |
| 非常规穿法出图失败 | 中 | 拆成独立阶段；沉淀生图经验卡 |
| 知识库跑偏或过时 | 中 | 候选 → 评测 → 人审；趋势类技巧带时效 |
| 品牌商品幻觉 | 中 | 只引用目录条目；链接定期巡检 |
| 单方案成本过高 | 中 | 简单方案单阶段；后台用小模型；提示缓存；成本上限 |

## 11. 成功指标（初版，M0 后校准）

| 指标 | 定义 | 目标 |
|---|---|---|
| 衣橱打标准确率 | 标注集上类目、颜色、材质、廓形 | ≥ 90% |
| 服装还原度 | 人工评分 ≥ 4 / 5 的效果图占比 | ≥ 80% |
| 方案专业度 | 造型师盲评 1–5 分 | ≥ 4.0 |
| 意外穿法命中 | 被收藏方案中含非常规穿法的比例 | ≥ 15% |
| 品牌链接有效率 | 推荐时链接可访问且在售 | ≥ 98% |
| 首图时延 | 单阶段 P50 / 多阶段 P50 | ≤ 40s / ≤ 120s |
| 单方案成本 | LLM + 生图 | M0 实测后定 |
